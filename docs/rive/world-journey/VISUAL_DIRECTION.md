# VISUAL DIRECTION

**Who may edit:** Astra only.  
Status: `DESIGN_READY`

Locked canon: Harbor RS, `paint-volt` `#c4a24a`, void `#05070b`, pack navy `#0e1a3a`, bone `#f3efe6`, gold `#e4c24a`. Collector, not cartoon. No HUD or stamps inside the `.riv`.

---

## Overall visual target

A premium original game-world presentation combining:
- console-quality polish
- contemporary art confidence
- designer-collectible dimensionality
- restrained anime/game energy
- mobile-first clarity

The scene should not look like a children’s learning app, a racing-game clone, or a flat website illustration.

## Courtyard

Harbor should read as a designed spatial environment:
- strong large shapes before small detail
- clear route readability
- controlled texture
- depth through scale/parallax/light rather than visual clutter
- dark void/edge treatment that supports the collector-window framing in React

The map must not contain a painted-in vehicle.

## Harbor RS

Top-down collector vehicle, pinned in frame.

Material:
- muted `paint-volt #c4a24a`
- vinyl/paint response rather than chrome
- dimensional but not toy-plastic
- readable wheel/tire separation
- silhouette strong enough for compact mobile crop

Heading offset is baked into the rest pose per technical contract.

## Light / atmosphere

Use restrained cinematic lighting:
- soft moving highlight/wander in full motion
- subtle environmental contrast
- enough shadow/contact to create dimensionality
- no strobing
- no blown highlights
- no low-contrast haze that harms readability

Boss may feel more energized through motion/light pacing, not a wholesale color-theme change.

## Motion aesthetic

Motion should feel:
- smooth
- deliberate
- mechanically credible
- quick to respond
- easy to read

Avoid:
- cartoon bounce everywhere
- excessive easing overshoot
- screen shake
- particle spam
- neon-racing clichés

## Compact crop priority

In compact surfaces, preserve in this order:
1. full readable Harbor RS
2. immediate road/route context
3. enough courtyard geometry to communicate movement
4. secondary lighting/detail

Decorative environment is expendable before the vehicle is.

## What we will not draw

- HUD
- XP
- score
- badges
- text labels
- stamps
- tap-to-rev prompt
- second car
- copyrighted characters or branded game motifs
- anime character IP
- PlayStation/Nintendo UI copies
